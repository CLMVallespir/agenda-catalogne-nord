# Agenda Catalunya Nord — Project Instructions

This project builds and maintains an automated, almost-zero-cost **cultural agenda for North Catalonia (Catalunya Nord)** — the five comarques Rosselló, Conflent, Vallespir, Capcir and Cerdanya. Its public name is **"Què fas?"**. Cultural associations send events by email to `agenda@clm.cat` or through a Typebot form. Both routes arrive at **one single Cloudflare Worker**: its `email()` handler parses the message, sends the text to the **Gemini API** for structured extraction, uploads any poster to **Cloudinary**, and appends one row to `pendents.json`; its `fetch()` handler takes the Typebot webhook and maps the already-structured form fields straight to a row, with no model call; its `scheduled()` handler sends the weekly per-comarca digest through **Brevo**. A single curator reviews the queue in **`curador.html`**, a static page that reads `pendents.json` and writes both it and `events.json` through the GitHub API. A static **GitHub Pages** site reads `events.json` and shows the agenda with comarca, category and date filtering, bilingual Catalan/French.

When working in this project, always follow these rules.

**Simplicity beats everything.** This is a one-person volunteer project that must stay repairable by a non-developer months later. Prefer longer, obvious code over clever code. One function = one job; explicit over implicit (`if (estat === 'publicat')`, never `if (fila[14])`); a one-line comment on every function; clear Catalan domain names (`carregaEsdeveniments`, `creaTargeta`, `analitzaCorreu`, `construeixFila`). A good self-test: could the owner reopen this file in six months and fix a bug without help?

**No dependencies, free tiers only.** No frameworks, build tools, npm, or external JS/CSS libraries. Vanilla JS everywhere. The single agreed exception is **`postal-mime`, vendored** — one pinned file copied into the repository with its version and source URL in the header comment; no `package.json`, no `node_modules`. Infrastructure is Cloudflare (Email Routing + Workers), GitHub Pages, Cloudinary, Brevo and the Gemini API — all free tiers, no paid infra, no database. Images live on Cloudinary, never in Git.

**No database, and no second place to keep state.** State lives in exactly two JSON files at the repository root: `pendents.json` (the curator's review queue) and `events.json` (the published source of truth). If a feature seems to need a third store, that is a design smell — check first whether the service doing the work already keeps the record. The digest's idempotency guard, for instance, is Brevo's own send log, not a file.

**Respect the data contract.** Sixteen string fields with exact names and order, identical across the extraction prompt, `pendents.json`, `events.json` and the frontend. Every field is a string; unknown values are `""`, never `null` and never omitted. Never rename, reorder or add a field without updating all four places together. Never trust the `id` the model returns — always rebuild it with `creaId(dataInici, titol)`, and coerce `comarca` and `categoria` to the allowed lists with `valorPermes(...)`.

**Secrets live in Cloudflare Worker Secrets**, never in code, never in logs, never in Git: `GEMINI_API_KEY`, `GITHUB_TOKEN`, `ADRECA_ARXIU`, `TYPEBOT_SECRET`, `BREVO_API_KEY` and the five `BREVO_LIST_*` list IDs. `CLOUDINARY_CLOUD_NAME` is not secret. The GitHub token is fine-grained, limited to this repository, `contents: write` only.

**Catalan-first and bilingual, everywhere user-facing.** Catalan is primary; French sits immediately below, smaller and in Georgia italic. Bilingual separator ` · `. Use curly apostrophes and correct contractions (`l'agenda`, `d'agost`, `a l'1`, `Fins al…`; French `1er`, `Jusqu'au`). Tone is open, cultural and welcoming — never activist or political. The one exception is `curador.html`, which is Catalan-only: its only user is the curator.

**Honour the design language.** Black-and-white-dominant chrome in both a light and a dark theme; the event posters carry the colour; the senyera palette (red `#b5121b` + gold `#fcdd09`) appears only as a small accent. Fonts: Fraunces (Catalan titles) + Montserrat (Catalan body/UI) + Georgia italic (French), self-hosted. The two languages never share a font. The public site's design is finished — don't redesign it.

**Confirm before scope creep.** Out of scope unless explicitly agreed: user accounts/login, an association self-submission portal, in-app event editing on the public site, comments/social features, analytics/tracking, any database, any server beyond the single Worker, any CSS or JS framework. If a request would break a constraint above, surface the tension and propose the simplest in-spirit alternative rather than silently breaking the pattern.

Before writing or changing anything, read the **Project Knowledge** document ("Agenda Catalunya Nord — Project Knowledge for Claude Chat") for the full architecture, the exact schema, the current build status, and the decisions already made — including which parts of the old Apps Script design are dead and must not be proposed again.
